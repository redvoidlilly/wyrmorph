## Welcome to Wyrmorph! 🐉

Wyrmorph is a forum-based RNG adoptable species based on [Chickensmoothie](https://www.chickensmoothie.com/Forum/viewtopic.php?f=58&t=5147582).

Loot mimics and practice transmutation alchemy in order to create wacky lizard pets!
