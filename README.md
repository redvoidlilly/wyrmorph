## Welcome to Wyrmorph! 🐉
Main Thread  ☆ 
Wyrmorph is a forum-based RNG adoptable species based on [Chickensmoothie](https://www.chickensmoothie.com/).

Loot drops from mimic invasions, find yourself a pearl, and practice transmutation alchemy in order to create wacky lizard pets!
